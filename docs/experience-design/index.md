Experience Design is an optional family entrypoint over five existing design building blocks.
It helps users describe an experience outcome without needing to know which design contract
should run first.

## Choose the entry path

- Direction or experience strategy → `ux-strategy`.
- Hypothesis pressure-test → `ux-provocation`.
- Interface usability inspection → `heuristic-audit`.
- Interface language and action clarity → `ux-writing`.
- Review against a declared design system → `design-system-intelligence`.
- Several concerns are connected → start with the family entrypoint.

The family selects one primary block and adds supporting blocks only when evidence requires
them. It does not implement designs, approve product decisions, or promote patterns.

See the canonical [skill contract](https://github.com/nevitonsantana/adaptive-skills/blob/main/skills/experience-design/SKILL.md)
for the source of authority.
