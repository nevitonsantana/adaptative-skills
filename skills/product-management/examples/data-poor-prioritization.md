# Example: data-poor prioritization

## Request

A team asks: "Rank these five feature requests with RICE so we can commit the next quarter." No reach data, shared outcome, or comparable effort estimate is available.

## Appropriate path

1. Use problem framing to identify the decision horizon and intended outcome.
2. Mark reach and impact as unknown instead of inventing values.
3. Reject RICE for the current evidence state.
4. Use a lightweight value-versus-effort discussion only if the candidates become comparable.
5. Route feature worthiness to `feature-value-governance` and discovery gaps to `product-management`'s discovery module.
6. Return a short evidence plan and a human-owned decision point.

## Failure

A numeric RICE table with fabricated reach, impact, and confidence would create false precision and hide that the team has not agreed on the outcome.
